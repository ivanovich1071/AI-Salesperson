# База знаний (RAG)

Все `.md`-файлы из этой папки автоматически подгружаются в системный промпт AI-продажника
(см. `src/lib/knowledge.ts`). Файлы читаются в алфавитном порядке, поэтому используйте
числовой префикс для управления порядком: `01-...`, `02-...`, `10-...`.

## Obsidian

Эта папка — готовый Obsidian-vault: в Obsidian выберите «Open folder as vault» и укажите
папку `knowledge/`. Все заметки vault'а автоматически попадают в контекст AI-продажника.
Локальное состояние (`workspace.json`) в git не коммитится, конфиг vault'а — коммитится.

## Как пополнять базу знаний

1. Положите новый `.md`-файл в эту папку (кейсы, отзывы, новые модули, FAQ, отраслевые сценарии).
2. Перезапуск сервера не обязателен в dev-режиме; в продакшене — перезапустить процесс.
3. Следите за суммарным объёмом: всё содержимое попадает в каждый AI-запрос.
   Мягкий лимит задаётся в `src/lib/knowledge.ts` (константа `MAX_KNOWLEDGE_CHARS`).
