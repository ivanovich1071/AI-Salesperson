# Как проверять видимость vibemind.by

Три уровня проверки, от быстрого к медленному:
техника (секунды) → боты в логах (минуты) → реальные ответы ИИ и позиции в поиске (недели).

---

## 1. Техническая часть — одной командой

```bash
npm run geo:audit -- https://vibemind.by
```

33 проверки: robots.txt и ИИ-краулеры, sitemap, `llms.txt` / `identity.json` / `ai.json`,
Schema.org (Organization, WebSite, Course, FAQPage, Person), уникальность title/description, h1 на каждой странице.

Норма — **100/100**. Если упало ниже 80, тот же аудит валит CI на пуше.

Отдельно посмотреть, что именно видит робот на конкретной странице:

```bash
curl -s https://vibemind.by/course | grep -o '<h1[^>]*>[^<]*'
```

## 2. Ходят ли боты — по логам сервера

Самая честная проверка: не «догадывается ли ИИ», а **приходил ли его краулер**.

```bash
ssh -i ~/.ssh/vibemind_deploy -o IdentitiesOnly=yes root@81.177.214.84 \
  'for b in GPTBot OAI-SearchBot ChatGPT-User PerplexityBot ClaudeBot Googlebot YandexBot Bingbot; do printf "%-16s %s\n" "$b" "$(grep -ci $b /var/log/nginx/access.log)"; done'
```

Кто есть кто:

| Бот | Чей | Что делает |
|---|---|---|
| `GPTBot` | OpenAI | обучение моделей |
| `OAI-SearchBot` | OpenAI | индекс для ChatGPT Search |
| `ChatGPT-User` | OpenAI | зашёл **по ходу диалога с пользователем** — самый ценный сигнал |
| `PerplexityBot` | Perplexity | индекс |
| `ClaudeBot` | Anthropic | обучение / поиск |
| `Googlebot`, `YandexBot`, `Bingbot` | классика | обычный индекс |

Grok (xAI) и Qwen своих публичных краулеров почти не гоняют — они берут веб через
поиск Bing/Google, поэтому проверяются только вживую (п. 3).

**Замер на 22.08.2026** (через час после деплоя, лог за сутки):
Googlebot 49, YandexBot 9, Bingbot 7, GPTBot 7, OAI-SearchBot 7, PerplexityBot 7, ClaudeBot 5, ChatGPT-User 4, Amazonbot 2.
Все ключевые уже ходят — это база для сравнения через месяц.

## 3. Живая проверка в нейросетях

Открыть каждый сервис и задать **одни и те же** запросы. Важно: спрашивать не «что такое ВайбМайнд»
(модель может знать из обучения и придумать), а так, чтобы ей пришлось лезть в веб.

Где проверять:

| Сервис | Что включить |
|---|---|
| ChatGPT | режим **Search** (иконка глобуса) |
| Perplexity | по умолчанию ищет |
| Claude | включить web search |
| Google AI Mode / Gemini | вкладка AI Mode в поиске |
| Grok (X) | включить DeepSearch |
| Qwen Chat | тумблер веб-поиска |
| Copilot (Bing) | по умолчанию ищет |

Набор запросов (задавать по-русски, менять раз в месяц не надо — нужна динамика):

1. `корпоративное обучение нейросетям в Беларуси` — есть ли мы в списке
2. `курс по ИИ для сотрудников компании Минск цена` — цитируется ли страница курса
3. `что такое ВайбМайнд` — правильно ли описывает
4. `vibemind.by` — открывает ли сайт и пересказывает ли верно
5. `сколько длится корпоративный курс ВайбМайнд и что входит` — проверка FAQ и llms.txt

Что записывать (заведите простую таблицу, дата / сервис / запрос):
- **упомянули?** да / нет
- **дали ссылку на vibemind.by?** — главный показатель
- **факты верные?** — цена, длительность, автор, формат
- **на каком месте** среди перечисленных

Если факт переврали — правим `public/llms.txt`, `llms-full.txt` и `/faq`: ИИ тянут ответы
именно оттуда, дословно.

## 4. Google и Яндекс

**Быстро, без панелей:**

```
site:vibemind.by            — сколько страниц в индексе (должно быть 5)
site:vibemind.by/faq        — дошёл ли конкретный раздел
```

Проверять в Google и в Яндексе отдельно. Пусто в первые 1–2 недели — норма.

**Панели вебмастера** (нужно один раз завести):

- Google Search Console — https://search.google.com/search-console
- Яндекс.Вебмастер — https://webmaster.yandex.ru

Подтверждение домена: обе панели дадут код. Их надо положить в env на сервере
как `GOOGLE_SITE_VERIFICATION` и `YANDEX_VERIFICATION` — код сайта уже умеет их отдавать,
после этого `systemctl restart ai-salesperson`.

После подтверждения — скормить `https://vibemind.by/sitemap.xml` в обеих панелях и смотреть:
- **Покрытие / Индексирование** — сколько страниц проиндексировано, какие отклонены и почему
- **Запросы** — по каким фразам показывают и куда кликают (появится через 2–4 недели)
- **Ошибки Core Web Vitals** — скорость

**Разметка:**

- Google Rich Results Test — https://search.google.com/test/rich-results
- Яндекс, валидатор микроразметки — https://webmaster.yandex.ru/tools/microtest/

Прогнать `/`, `/course`, `/faq`. Ждём: Organization, WebSite, Course, FAQPage, Person — без ошибок.

## 5. Сроки — чтобы не пугаться тишины

| Когда | Что должно быть |
|---|---|
| сразу | аудит 100/100, боты в логах |
| 3–7 дней | появление в `site:` Google |
| 2–4 недели | Яндекс подтягивается, в Search Console идут показы |
| 1–2 месяца | ИИ начинают цитировать по прямым запросам (vibemind.by, «ВайбМайнд») |
| 3–6 месяцев | попадание в общие подборки («курсы по ИИ в Беларуси») |

Разметка и `llms.txt` дают ИИ *возможность* процитировать точно. Само по себе это не
поднимает в выдаче — дальше решают упоминания на других сайтах и свежесть контента.

---

## Регламент

- **раз в неделю:** `npm run geo:audit -- https://vibemind.by` + боты в логах
- **раз в месяц:** 5 запросов по всем ИИ-сервисам в таблицу + `site:` в Google и Яндексе
- **после любой правки текстов:** синхронизировать `public/llms.txt` и `llms-full.txt` с сайтом — иначе ИИ будут цитировать устаревшее
